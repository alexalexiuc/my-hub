# shared utils — inventory

One entry per file in `packages/shared/src/utils/`. Loaded when working in this folder; hub and
mcp-server work should read it before writing a helper (see the root `CLAUDE.md`).

> Before writing any utility or component, check the list below. If the function has general purpose (string, number, date, array, etc.), it belongs here even if only one place uses it currently.

- `dates.ts` — Date/time helpers: formatting (YYYY-MM-DD, UTC, locale), timezone resolution (offset + IANA), current/relative date strings (`currentDateString`, `dateStringDaysAgo`, `localDateString`), ISO week arithmetic, month/week label formatters (`shiftMonthStr`/`formatMonthStr`/`formatMonthShortStr`, `shiftWeekStr`/`formatWeekRangeStr`), `monthsBetweenStr(from, to)` (signed whole calendar months between two YYYY-MM strings), addDays/addHours/addMinutes, `shiftDateStr(dateStr, n)` (shift a YYYY-MM-DD string by n calendar days, all-UTC), calendarDays, formatDayHeading, fmtDuration, formatSegmentTime; calendar utils (getMonthStart/End, startOfWeekMonday, isSameDay, toDate, startOfDay, `monthEndStr(month)` — last day of a YYYY-MM month (UTC), `buildMonthGridDays(month)` — full Mon–Sun weeks covering a YYYY-MM month for a 7-column grid); HTML input formatters (toDateInputValue, toDateTimeLocalValue); timezone display (getTimezoneNamePart, normalizeOffset, getTimezoneBadge, getFullDateTooltip); `getCurrentWeekDays` (ISO week Mon–Sun with YYYY-MM-DD + short labels)
- `objects.ts` — Object helpers: `omitUndefined` (strips `undefined` props), `omitNullish` (strips `null` and `undefined` props), `trimOrNull(val)` (trims string; returns `null` for empty, `undefined` unchanged — pair with `omitUndefined`), `getEnvVar(key, default?)` (reads `process.env[key]`, throws if missing and no default provided — use this instead of `process.env` directly)
- `arrays.ts` — Array helpers: `dedupeTrimmed(values, seen?)` — trims, drops blanks, drops case-insensitive duplicates (keeps first occurrence); pass `seen` to exclude already-known values
- `coordinates.ts` — Geographic coordinate utilities: `validateCoords` (Zod, range checks, both-or-neither), `isFiniteCoordinate`, `hasValidLatLng`, `parseCoordinatePair` ("lat,lng" string), `parseGeoUri` (geo URI), `containsPlusCode` (Plus Code detection)
- `withBackoffRetry.ts` — Promise retry with exponential backoff: `withBackoffRetry(fn, { retries, delay, shouldRetry })`
- `portfolio.ts` — Portfolio math (pure): `projectPortfolioGrowth(opts)` — monthly compound-growth projection series (`value_{m+1} = value_m × (1+r)^(1/12) + contribution`); `PROJECTION_HORIZON_MONTHS` (120); `sumAllocations`/`allocationsSumTo100`/`ALLOCATION_SUM_TOLERANCE` — target-allocation validation; `computeContributionCadence(opts)` — DCA schedule adherence: accrues one `plannedMonthlyContribution` per calendar month from `anchorMonth` through the current month inclusive, draws contributed cash against it, and returns both the signed `difference`/`monthsDifference` and a paid-through date (`coveredThroughMonth`, `nextContributionMonth`, `dueNow`, `monthsAhead`, `amountDueNow`); a tolerance band of `tolerancePct`% of one contribution (default 10) keeps a slightly-off contribution `on_track` and still counts its month as funded; returns null when there is no plan
- `calories.ts` — TDEE/calorie-target calculation: `calculateBMR` (Mifflin-St Jeor), `calculateCalorieTargets` (applies goal offset, floors, caps), `profileToTargets` (profile + latest weight → targets; single home for the field mapping), `hasDuplicateMealSlot` (weekly-menu "one meal per slot" rule), `mealOrder(gymTime)` (display order of a day's meal slots; places pre/post-workout around the training session), `dayTargetKcal` / `dayCalorieTargets(profile, weightKg, date)` (one day's ceiling+floor including the gym-day bonus — single owner of that rule), `latestWeightKg(measurements)`, `ActivityLevelMultipliers`
- `weight-goal.ts` — Weight-goal projection + trend maths (pure): `dailyGoalDeltaKg(goalType, weeklyRate)` (per-day change a weekly rate implies), `resolveGoalAnchor(profile, samples)` (the fixed point a projection runs from — the profile's stored `goalStartDate`/`goalStartWeightKg`, else the oldest sample flagged `inferred`), `projectedWeightOn(anchor, dailyDelta, date)` (cumulative goal line, extends both directions), `buildWeightTrend(samples, alpha?)` (EMA smoothing of raw weigh-ins; `WEIGHT_TREND_ALPHA` = 0.1 — compare the trend against a projection, not single readings, since daily scale noise exceeds a weekly goal. Decay is **per day elapsed**, not per reading: the carried weight is `(1 - alpha) ^ daysElapsed`, so a four-week gap nearly resets the trend to the next reading instead of dragging a stale one forward. Readings sharing a date are averaged into one value first, and both are returned carrying that day's trend), `trendRateKgPerWeek(points)` (least-squares kg/week the trend is actually moving), `trendOn(points, date)` (trend value as at a date, for week-over-week deltas), `goalJourney(anchor, targetKg, currentTrendKg, expectedDirection?)` (distance covered towards a goal weight; clamps 0–100% and refuses a target on the wrong side of the baseline), `projectGoalDate(currentTrendKg, targetKg, rateKgPerWeek, today)` (when a target is reached at a given rate — fed the achieved rate it forecasts, fed the goal rate it restates the plan; null beyond ten years), `isAheadOfGoal(goalType, delta)`, `daysBetweenDateStr(from, to)`; Types: `WeightSample`, `WeightTrendPoint`, `GoalAnchor`, `GoalJourney`
- `travel.ts` — Trip domain helpers: `deriveTripStatus` (computes Planned/Active/Completed/Cancelled), `isTransportBookingType`
- `finances.ts` — Finance domain helpers: `getCurrencySymbol(currency)` — maps currency code to display symbol (USD→$, GBP→£, EUR→€), falls back to the code itself; `isPayeeRequired(type)` — returns whether a transaction type should involve payees (false for transfers); `formatCardLastFour(cardLastFour)` — masks each comma-separated last-4 group individually (e.g. "1234,5678" -> "•••• 1234, •••• 5678") for cards also loaded into Apple Pay/Google Pay; `quoteTransferRate(sent, sentCcy, received, receivedCcy)` — effective rate of a cross-currency transfer as `{ rate, base, quote }`, quoted weaker-per-stronger (6033.03 MDL → 300 EUR = 20.1101 MDL per EUR); `isLiabilityAccount(type, direction?)` — whether an account subtracts from net worth/available (loans, credit cards, and Borrowed/Lent only when `direction` is `received`; money lent is an asset) — the single classifier for every net-worth/available view
- `vacation.ts` — Vacation pay engine (pure, Moldovan HG 426 method, rule-set driven): `createVacationModel(input)` → `.rateFor(date)` (average daily rate for a leave starting in that month: earnings over days actually worked, × working days / (calendar days − art. 111 holidays) for `calendar_day` rule sets; leave days in the window are subtracted from days worked, a base raise inside the window restarts it, no work in the window falls back to the latest worked months within 12), `.calendar(from, to)` (per-day `[date, netDelta, netAmount, balanceCost, markers]` assuming a leave starting in that day's month), `.evaluateSpan(start, end)` (span totals; rate fixed by the start month, pay forgone by each day's month), `.balanceOn(date)` (daily accrual `entitlement / days-in-year`, leave charged oldest rule-set bucket first — pre-2027 calendar days before 2027 working days), `.findBestWindows(opts)` (`leaveDays` → max_money / max_rest, `restDays` → min_balance / max_money; non-overlapping, skips recorded leave), `.warnings()`; `classifyVacationDay` (workday / rest / holiday — an art. 111 holiday stays a holiday on a weekend; transferred days follow the Government transfer), `vacationRangeError`
- `errors.ts` — `UserInputError` — throw from a service for invalid input or missing setup, with a message written for the user. Hub `route()` answers it with a 400 `{ error }`; MCP `wrapToolHandler` logs it as handled (warn, not error) and the SDK returns the message as a tool error. Subclass it per domain instead of adding per-caller catch wrappers
- `holidays-md.ts` — Moldovan public holidays (pure): `orthodoxEasterDate(year)` (Meeus Julian computus +13 days → Gregorian, valid 1900–2099), `moldovaPublicHolidays(year)` (the 13 Labour Code art. 111 national days incl. Easter, Easter Monday and Blajini; hram days and Government transfers are not derivable and not included)
- `logger.ts` — Minimal logger with ISO timestamps: `logger.info/warn/error` — wraps `console.log/warn/error` with an ISO 8601 prefix. Use in worker and server startup code where no framework logger is available.
